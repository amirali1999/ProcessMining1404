این پروژه برای تحلیل انطباق فرآیند طراحی شده و با استفاده از مدل پتری‌نت (PNML) و لاگ رویداد (CSV)، انطباق هر case را با مدل بررسی می‌کند.
الگوریتم اصلی مورد استفاده Token Replay از کتابخانه PM4Py است.

## هدف پروژه
- بارگذاری مدل فرآیند (Petri Net)
- بارگذاری لاگ رویداد
- اجرای Token Replay
- جداسازی caseهای منطبق و غیرمنطبق
- ذخیره خروجی در فایل‌های CSV

## ورودی‌ها
- فایل مدل با فرمت PNML
- فایل لاگ رویداد CSV شامل ستون‌های زیر:
  - case_id
  - activity
  - timestamp

## خروجی‌ها
- فایل `compliant_<model>_<log>.csv` شامل کیس‌های منطبق
- فایل `non_compliant_<model>_<log>.csv` شامل کیس‌های غیرمنطبق
- درصد و تعداد انطباق نیز در فایل JSON خروجی ذخیره می‌شود.

## نسخه‌های تست‌شده

- pandas: 2.3.1
- numpy: 2.0.2
- matplotlib: 3.9.4
- networkx: 3.2.1

## نحوه اجرا
1. فایل‌های PNML و CSV را کنار نوت‌بوک قرار دهید.
2. نوت‌بوک `G6.ipynb` را اجرا کنید:

3. مسیر فایل‌ها را در کد تنظیم کنید:

   ```python
   pnml_file_path = "alpha_model.pnml"
   log_csv_path = "SP_DF_cleaned.csv"
   ```
4. تمام سلول‌ها را اجرا کنید تا خروجی‌ها تولید شوند.

## نکات

- اگر ساختار CSV متفاوت باشد، لازم است بخش بارگذاری لاگ در کد مطابق نام ستون‌های فایل اصلاح شود.


## خروجی JSON

در کنار فایل‌های CSV، پروژه یک فایل خروجی JSON نیز تولید می‌کند که خلاصه‌ای از وضعیت انطباق را ارائه می‌دهد. این فایل شامل اطلاعات زیر است:

- نام فایل مدل
- نام فایل لاگ
- تعداد کل کیس‌ها
- تعداد کیس‌های منطبق
- تعداد کیس‌های غیرمنطبق
- درصد انطباق و عدم انطباق

نمونه خروجی JSON:

```json
{
    "model_file": "heuristic_SP_DF_cleaned.pnml",
    "log_file": "SP_DF_cleaned.csv",
    "stats": {
        "total_cases": 100000,
        "compliant_cases": 47127,
        "non_compliant_cases": 52873,
        "compliant_percentage": 47.127,
        "non_compliant_percentage": 52.873000000000005
    }
}
```
