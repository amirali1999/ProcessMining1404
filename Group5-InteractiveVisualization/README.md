# Group 5 – Interactive Visualization

This folder contains the interactive visualization module of the Process Mining project developed by **Group 5**, implemented using the **Django** framework.

## Overview
- HTML templates are located in `core/templates/core`
- `base.html` is the parent template for:
  - `petri-net.html`
  - `upload.html`
  - `dashboard.html`
- UI is built with **Bootstrap 5.3.3**, stored locally in `core/static/core`

## Routing and Views
- URL configuration is handled in:
  - `Project/urls.py`
  - `core/urls.py`
- View logic is implemented in `core/views.py`

## PNML to PNG Conversion
To visualize Petri Nets generated by Group 4:
- Run the script `core/pnml-to-png.py`
- PNML files are converted to PNG images
- Output images are saved in:

core/static/core/output

## Notes
This module is independent from other project components and focuses on web-based visualization of process mining results.
